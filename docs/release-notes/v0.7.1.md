## Documentation

- `PRIVACY.md` now lists the HTTP custom data source (`dbBackend: "http"`) under network access, in both English and Japanese: what is sent (tickets, execution graphs, artifacts including their content, projects, and labels), where (only the URL you configure), and how it is authenticated (the configured token as an `Authorization: Bearer` header; HTTPS and a token are required for any non-loopback URL, and redirects are not followed). The same policy's "where your data is stored" and "deleting your data" sections now cover the HTTP data source too. This had been missing since v0.6.0.
