## Highlights

- **Engine binary fetched on first run.** The plugin now ships `bin/graph-engine` shims (sh and `.cmd`) that download the `graph-engine` release binary for the plugin's version on first use, verify it against the release's `checksums.txt`, and cache it per user (`$GRAPH_OPS_ENGINE_DIR`, or `${XDG_CACHE_HOME:-~/.cache}/graph-ops/engine`; `%LOCALAPPDATA%` on Windows). Installs that run no install-time script now work.
- **Web UI approvals resume `process-ticket`.** A new `wait-node` command lets `process-ticket` wait for an approval decision made in the Web UI and continue automatically.
- **Per-environment project paths.** A project's local path is no longer stored in the database (`projects.work_dir`); it lives in each environment's `graph-config.json` under `projectPaths`. A new project setup dialog creates a project or links an existing one to a local path.

## Changes

- Ticket priority is always HIGH, MEDIUM or LOW (default MEDIUM) and is shown as a one-character badge. Existing tickets without a priority are backfilled to MEDIUM; `refine-ticket --priority none` and `PATCH /api/tickets/{id}` with `"priority": null` are now rejected.
- The create-ticket dialog replaces the title/description fields with a single request field; the request text is kept if the launch fails.
- Web UI launch prompts use the namespaced `/graph-ops:*` slash commands.

## Accessibility

- Web UI modals are keyboard- and screen-reader-accessible (focus trap, Escape to close, focus return, contrast fixes; Escape is ignored during IME composition).

## Upgrade notes

- The `projects.work_dir` column is dropped automatically the first time the new version opens the database, and its values are **not** migrated. Stop any UI server started before the update, then set each project's local path again (App Settings > project management, or run `/graph-ops:ui` in the project directory and choose the existing project).
- Teams sharing a MySQL database should upgrade together: older binaries cannot create or read projects once the column is gone.
- API: project responses contain `local_path` instead of `work_dir`, and `POST`/`PATCH /api/projects` accept `local_path`.
