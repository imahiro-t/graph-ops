## Highlights

- **Ticket labels.** Projects can define labels, tickets can carry them, and the ticket list can filter by them. Labels are managed in a new Labels settings tab and are available through the store, engine, HTTP API and CLI (`--label`, restricted to registered labels). The label tables are created automatically.
- **Unified ticket-list filters.** The status, assignee, priority and label filters now share one control: an empty selection means "All", options within a filter match with OR, filters combine with AND, and every panel has a "Clear selection" button. The assignee filter is now multi-select and offers "Unassigned".
- **Installation via `git-subdir`.** The marketplace entry now installs the plugin from `packages/plugin` with a `git-subdir` source pinned to the release tag, instead of a command source. The plugin's `bin/graph-engine` shim downloads the matching engine binary on first use.

## Changes

- Inline text and Gherkin artifact previews (node detail, Gherkin tab, Artifacts tab) are capped at 16rem and scroll, so tickets with many artifacts stay readable.

## Accessibility

- Scrollable artifact previews are keyboard-focusable regions with a focus ring that meets 3:1 contrast, and each one's accessible name includes the artifact's creation time so same-named artifacts can be told apart.
- Label editing and label management are keyboard- and screen-reader-friendly.

## Documentation
