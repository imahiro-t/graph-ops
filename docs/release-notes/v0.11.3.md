## Changes

- **Autopilot child sessions open as Terminal.app tabs instead of falling back to new windows when the screen is unlocked.** Looking into the run files and macOS's unified log showed that the tab fallbacks with the screen unlocked were almost all a synthesized Cmd+T that never reached Terminal: Terminal and the orchestrator's window stayed in front, yet no new tab appeared anywhere (9102). The earlier fixes (DFLT-00154, DFLT-00183, DFLT-00361, DFLT-00362) had all changed what happens after Cmd+T, so none of them could help with that. The tab script now opens the tab by pressing Terminal's New Tab menu item over Accessibility (found by its Cmd+T shortcut, not its title, and only when exactly one such item sits next to the Cmd+N item), and sends Cmd+T only when no such item is found. It also checks again, right before opening the tab, that Terminal and its window are still in front, and brings them back (at most twice) when they are not. When no tab has appeared about 2 seconds after the first attempt, it tries once more by Cmd+T, after reading the tabs again so that a first tab that is merely late is taken instead of a second one being opened. A tab that opened only at the retry is counted in the run file's `terminal_retried_tabs`; a second new tab that appears after the retry (most likely the first attempt's, appearing late) is logged as `stray_tab`, counted in `terminal_stray_tabs`, and the session still runs in the tab taken. `terminal_late_tabs` and `late_tab` now also cover a first attempt's tab taken right before the retry. Every failure records more for the next investigation: `open_method` (`menu`, `menu-failed`, `keystroke-no-menu`, `keystroke-retry`), `retried`, `retry_frontmost_app`, `refocused`, `front_window_id_before`, `secure_input` (who holds secure keyboard entry) and `hid_idle_ms` (time since your last input), and two new phases, `menu-pressing` and `menu-pressed`. The `osascript` limit is now 30 seconds (from 20), the wait for the tab lock 35 seconds (from 25), and a launch's worst case about 81 seconds (from about 59). While the screen is locked, sessions still open in new windows (a macOS restriction; that was 83% of the fallbacks looked into). docs/autopilot.md describes how the tab is opened, the investigation, and the remaining trade-off (a late first tab and the retry's tab seen in the same read is still a 9104) (DFLT-00377).
