## Highlights

- **Editable plan and review templates.** Settings now has a Templates tab where the Execution Plan, Review and Report templates can be edited. New endpoints: `GET`/`PUT /api/settings/plan-template` and `/api/settings/review-template`.
- **Multi-line Claude launcher prompt.** The launcher prompt is now a resizable textarea: Enter inserts a newline and Cmd/Ctrl+Enter launches.

## Changes

- Plan and review templates now resolve as team → user → English plugin default; language-based template switching was removed. `onboarding` copies the Japanese templates into the user tier when Japanese is selected, asking before replacing a different existing override.

## Fixes

- Cmd/Ctrl+Enter no longer launches Claude with a whitespace-only prompt.
- Template editor: improved text contrast, and focus is kept after saving.

## Documentation

- README updated to match the current plugin (namespaced `/graph-ops:*` commands, Web UI features, configuration) and now includes Web UI screenshots.
- Clarified how to update the plugin (`claude plugin update` from a regular terminal).
