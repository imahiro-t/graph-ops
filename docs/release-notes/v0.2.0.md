## Highlights

- **Windows terminal launch support.** The Web UI's terminal-launch buttons now work on Windows: GraphOps prefers Windows Terminal (`wt.exe`) and falls back to `cmd.exe`, running a generated PowerShell script so multi-line prompts survive intact.

## Fixes

- Agents no longer copy the leading meta-instruction comment of the plan / review / review_gate / report templates into saved artifacts.
- The plan / review / review_gate node-type defaults and the `graph-node-agent` definition are now language-neutral: they follow the headings and verdict words of whichever template was fetched instead of hardcoding Japanese ones. The instruction comments were removed from the plan and review Markdown templates.

## Documentation

- Documented the `terminalCommand` setting in `graph-config.json` as a troubleshooting workaround for terminal launch.
