Investigate the topic this ticket asks about and report what you found. This
node does not change code -- it produces the findings that later nodes act on.

## Procedure

1. Read the ticket's description and any artifacts earlier nodes have already
   saved, to fix what the topic actually is.
2. Investigate that topic, gathering evidence from the repository and from
   whatever other sources the ticket points at.
3. Draw your conclusions from that evidence, and keep the reference behind
   each one.

## Artifacts

Save the findings, the conclusions, and the references backing them as one
`text` artifact via `add-artifact`. Give it a name that describes its content.
